# Smart-Energy-Meter-Monitoring-System-
Smart Energy Meter Monitoring System . An IoT-based Smart Energy Meter Monitoring System developed using ESP32 to measure, monitor, and analyze power consumption in real time. The system provides live energy usage data, alerts for abnormal consumption, and enables efficient energy management through a user-friendly monitoring interface.

A real-time Smart Energy Meter Monitoring System developed using ESP32 for monitoring electrical energy consumption. The system measures voltage, current, power, and energy usage, displays live data, and helps users track electricity consumption efficiently. It supports IoT-based monitoring, enabling better energy management and reducing power wastage.

# Features
-Real-time energy consumption monitoring
-Voltage and current measurement
-Power usage calculation
-ESP32-based IoT implementation
-Live data visualization
-Energy-saving and monitoring support

# Technologies Used
-ESP32
-Arduino IDE
-IoT Monitoring
-Embedded Systems
-Wokwi Simulation
